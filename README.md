# Protótipo — Biblioteca de Estudos

Protótipo estático em HTML, CSS e JavaScript puro para uma biblioteca de disciplinas.

## Ideia central

A organização principal é por **nome da disciplina**, e não por semestre. Isso permite:

- reutilizar uma disciplina entre diferentes períodos;
- compartilhar disciplinas com colegas;
- pesquisar por nome, código ou assunto;
- manter a interface independente da estrutura acadêmica de cada pessoa.

## Estrutura

- `index.html` — estrutura da interface.
- `styles.css` — apresentação e layout responsivo.
- `app.js` — dados de demonstração e interações.

Não há dependências externas.

## Abrir

Abra `index.html` diretamente no navegador.

## Próxima etapa

Uma implementação real pode transformar cada disciplina em uma unidade de conteúdo versionada no GitHub, mantendo o frontend leve e carregando apenas os dados necessários para a tela atual.
